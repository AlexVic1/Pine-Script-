Pine Script for scanning short-term assets:
• Criteria:
o Detect breakouts above moving averages (EMA 9 and EMA 21).
o Higher than average trading volume.
o Detect momentum candles.

How to use?
1. Open TradingView.
2. Go to Editor -> Pine Script.
3. Paste the code and save the script.
4. Run it on charts with timeframes of 1-5 minutes.

The script: What does it do?
The script helps you identify trading opportunities in short-term timeframes (1-5 minutes) according to three criteria:
1. Price breakout above moving averages (EMA 9 and EMA 21):
o Used to identify a positive trend (uptrend).
2. Higher than average trading volume:
o An indication that there are many participants in the market, which can confirm the trend.
3. Momentum Candles:
o Candles that show strong and rapid price movement.
When all three criteria are met, the script marks an "entry signal" on the chart.
